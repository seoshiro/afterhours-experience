# AFTERHOURS

A fictional night imagined as an exhibition catalogue escaped into a city poster. Acid lime is the cover. Coral and ultramarine punctuate the three acts. Ink rules, print marks, circular interference fields, oversized cropped type, and generous editorial voids make the rhythm. Use native scroll with sticky labels; never hijack scrolling. No real artists, venues, sponsors, commerce, accounts, or collection of personal data.

Core: editorial hero, three acts, searchable/filterable programme, local shortlist, mutable original SVG poster with PNG/SVG export. Sound only if explicitly activated, with a clear stop control. No WebGL needed.

21st catalog search attempted on 2026-10-23; service returned `catalog search failed`. No paid code or components used. Local UI Build and Review workflow applies to original components.
